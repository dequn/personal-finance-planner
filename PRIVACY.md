# Privacy

Personal Finance Planner is distributed without personal financial data.

The repository may contain reusable workflows, schemas, calculators, bounded
public-source summaries, and fixtures explicitly classified as synthetic. It
must not contain real identities, accounts, holdings, balances, transactions,
goals, policies, statements, screenshots, credentials, Workspace databases,
host transcripts, or private-repository history.

Confirmed user state is written only after explicit confirmation to an external
Workspace selected by that user. The Plugin does not discover private folders
or package Workspace data.

Every candidate release must pass the repository's allowlist,
prohibited-literal, fixture, symlink, secret, package-boundary, and manual
staged-diff checks. Uncertainty blocks release.
