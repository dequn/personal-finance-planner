# Repository instructions

- Keep this repository free of personal financial data, credentials, account
  facts, screenshots, host traces, and private-project history.
- Preserve `personal-finance-planner` as the technical Plugin and MCP identifier;
  use Personal Finance Planning Core as the user-facing name.
- Reusable stable behavior belongs here. Real practice, private evidence, and
  unstable experiments remain in the integrating private Project.
- Promote one capability at a time and keep one implementation source and one
  writable state authority.
- Calculations and persistence must be deterministic and validated. User
  confirmation is required before confirmed state is written.
- Do not add transaction, redemption, subscription, FX, leverage, or credential
  collection tools.
- Use synthetic fixtures only and run privacy, manifest, MCP, and contract tests
  before every candidate release.
